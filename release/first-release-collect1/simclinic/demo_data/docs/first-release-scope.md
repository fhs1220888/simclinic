# SimClinic 首版范围、缺口和完成条件

日期：2026-10-11。当前首版形态：本地 Python CLI、诊断报告、现成补丁与可运行展示。产品承诺是“帮助开发者定位已记录的问题，并复测具体修复”，证据范围限固定 Foam-Agent v2.1.0 和 Foundation 10/simpleFoam 小型稳态不可压缩单相工作流。

已增加精简可安装交付`0.11.0+demo1`：wheel与源码包只包含已有诊断核心、同一演示、两个补丁、必要源码/许可、六份记录和74个注册证据。独立Python3.9.6/3.12.14虚拟环境安装通过，各5项包内验收通过；隔离演示在禁止Python读取原仓库和联网时仍通过。无需维护者全量仓库或历史库存。

新增试用交接资料位于`release/first-release-handoff`：逐步使用指南、固定Agent记录来源/字段映射、验收清单、空白合成模板与调用已有CLI的示例。交接包沿用相同wheel/源码包，不新增产品命令或采集器；仓库外Python3.9.6/3.12.14各跑通9条使用命令与不覆盖检查。最终交付为`dist/simclinic-first-release-handoff-20261011.zip`。

现增加现场采集分发`0.11.0+collect1`，入口为`simclinic collect`。复用既有Collector、固定执行源码与原通道验收，自动输出新记录、证据与体检；补丁版在新沙箱应用已有补丁，用第二次采集记录比较复测。范围是原演示的Foam-Agent执行服务段，明确full_agent_workflow=false；未引入完整模型图或其他Agent。交付与使用说明见`release/first-release/COLLECT.md`。

## 当前能交付

- 统一记录导入、五项行为体检、带事件/文件定位的 Markdown 和 JSON 报告。
- 区分执行、数值和参考验收；缺失证据保持未知。
- 对现成问题提供可读、可应用的修复补丁。
- 一条命令展示“exit 7误报成功→实际应用补丁→同条件正确报告失败”，并保留正常对照。
- 实际应用结果接口补丁，展示真实CFD结果的当前身份读取与旧身份拒绝。
- 用精选真实归档展示正常质量保持和“End不等于完成”的负例；附完整展示报告、现场回执和讲解稿。

本次演示只新增小型Shell进程和接口调用。归档体检、读取已有验收观测与执行新CFD实验是不同的动作。没有新模型调用、求解、采样或渲染。

## 本地演示验收

| 条件 | 验收方式 |
| --- | --- |
| 一条命令可运行 | Python3.9+、Git、Bash；不要求Docker或模型凭据；新目录输出 |
| 真正应用补丁 | 新沙箱中执行两个补丁的git apply --check和git apply，与已有测试快照一致 |
| 确实复现并修正行为 | 同一exit 7脚本在基线和修改版均真实退出7；仅执行成功报告从True变False |
| 正常行为保持 | exit 0现场对照两版成功；正常CFD历史归档两版原验收满足 |
| 身份负例正确拒绝 | 当前允许；不同run/input及未知上下文分别拒绝 |
| 不把诚实失败包装为完成 | 原故障任务两版都未完成；提前结束数值和参考仍未满足 |
| 证据可查看 | HTML、MD、JSON及精选原始证据副本可访问；summary状态必须为pass |

这些条件定义本地演示完成，不等同于公开发布完成或证明整体收益。

## 尚未得到的结论与后续范围

自然恢复收益仍无法判断：已完成自然观测没有符合恢复资格的故障；注入恢复不能替代自然证据。稳定节省、整体Agent优化、跨Agent和跨物理机制推广同样未证明。新的真实执行仍受原预算和独立授权约束，旧停止批次不续跑、不补配对。

保留已经完成的字段选择、输入正文和有限恢复研究作为扩展证据，不把它们全部塞入首版快速入口。当前演示只针对两个现成补丁及一个质量对照。

暂不加入网页产品、MCP服务、自动调参、额外物理机制、全项目库存审查或新的执行冻结。预算瓶颈留在独立研究清单，先完成上述可分发性和使用闭环。
